# 用户金额统计及简历界面正式发布记录

文件作用：记录 2026-10-11 用户管理金额统计、简历添加入口与官网下载页的实现口径、验证结果和恢复材料，不包含账号凭据或个体资料。

## 功能与统计口径

- 用户管理在今日注册和绑定程序之后增加剩余余额、充值金额，窄屏按项换行。
- 剩余余额 = `SUM(users.ai_balance_units) / 10000 - COUNT(users) * 0.50`。统计所有当前用户，不随列表搜索、分页或今日注册人数变化；负数保留，显示四位小数。
- 赠送扣除额是用户明确要求的固定每人 0.50 元，仅用于此统计；不修改用户余额，不跟随新的注册赠送配置变化。
- 充值金额 = 所有 `order_type='ai_balance' AND status='paid'` 的 `payment_orders.amount_cents` 合计 / 100；显示两位小数，不计会员、未支付、取消、失败订单，不受订单列表 500 条上限影响。订单实付金额是累计口径，未改成退款净额。
- 复用 `/api/admin/users` 的全局 `stats`，没有新建接口或数据库字段。超管权限保留；公开统计接口不暴露资金数据。
- 后端使用整数汇总和十进制字符串，前端使用字符串与 BigInt 显示，避免大金额经过浮点转换；缺失或无效字段显示 `--`。
- 简历姓名后紧跟手机号，头像垂直居中，经历仅公司名称加粗。瓜瓜使用用户提供的原始 JPG，保留内置示例只读属性。
- 添加弹框直接切换 AI 批量上传、手动添加、浏览器插件一键导入，切换保留未提交草稿；插件指引跳转 `/download#browser-extension`。
- 官网将本地程序、浏览器插件分区；本地更新记录默认三条，可展示更多和收起。Chrome 1.0.3 及现有后台下载配置不变，Firefox 仍按用户之前要求等待稳定后开放。
- 旧本地程序的批量导入接口返回纯文本 404 时，展示更新提示及下载入口，不再显示 JSON 解析英文错误。本机当前 6.2.10.1，使用 AI 批量导入需更新到已发布 6.2.10.3；本轮未安装或重启用户本地程序。
