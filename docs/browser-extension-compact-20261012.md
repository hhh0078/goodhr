# GoodHR 简历插件 1.0.4

本次以 `main` 的 `bad26103` 创建独立分支 `codex/extension-compact-20261012`，
对照本机 `D:/work/headhunter-system/browser-extension` 的 himatch 0.5.2。

## 页面与操作

- 识别可见简历后直接展开 420px 宽的浮窗。手动收起后同人不反复弹出；换人重新展开。
- `floating.html` / `candidate-ui.js` 只包含候选人、查重、手机号、岗位、备注与简历操作。
- `ui.html` / `ui.js` 只包含账号登录、退出、连接本地程序、一次用途授权及版本更新。
  招聘页面只能加载独立浮窗资源，浮窗后台消息不能登录、配对或改变授权。
- 添加和更新直接提交，取消二次确认。相似或多条精确记录仍由用户选择更新目标，
  隐藏重复、手机号校验、行版本冲突与幂等保护保留。
- 岗位采用搜索与三行单选滚动列表。备注两行，操作使用小按钮；移除长说明和重复标题。
- 完整履历与头像采集继续保留，未读到的空字段不会清空旧资料。
- 新人先创建简历，再分别保存备注与岗位推荐；已有资料更新不顺带保存备注。
  失败只重试失败项，草稿和幂等键按账号与候选人隔离。
- 图标取自官网 `public/brand/goodhr-logo-transparent-512.png`，统一使用绿色主题。

## 强制更新

继续复用后台配置和公开接口 `/api/system/browser-extension`，统一版本号。
确认官网版本高于当前版本后，工具栏和浮窗显示醒目警示块，
点击“立即更新”打开 `https://goodhr.58it.cn/download#browser-extension`。

旧版的简历、头像、备注、推荐、AI生成及保存操作同时在界面和插件后台拦截。
本地预览、查重、读取记录和取消既有 AI 任务保留。已确认的版本要求持久化，
离线或后台重启不会抹掉；升级达到所需版本后解锁。
公开检查合并并发请求，每分钟复用一次；主动检查可立即刷新。
首次缓存读取也合并，防止迟到旧缓存覆盖新版要求后误放行写入。

此行为从 1.0.4 开始生效。开发包没有浏览器商店的自动安装能力，更新需下载后重新加载。
本次提供 Chrome 包供重新加载验收；不更改云端发布配置、不重启生产服务或操作真实简历。
Firefox 继续保留源码兼容，按此前要求待 Chrome 稳定后再验收分发。

## 重新加载

正式下载页的新安装流程为：下载插件包后无需解压，打开 `chrome://extensions` 的开发者模式，
再从浏览器下载记录把安装包直接拖入扩展管理页，并按 Chrome 提示完成安装。
本节原有的解压目录方式只用于当时的开发验收，不再作为普通用户教程。
