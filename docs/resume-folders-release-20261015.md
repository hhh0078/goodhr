# 收藏夹分离与页面优化发布记录

文件作用：记录2026-10-15原简历标签与手动收藏夹分离、页面紧凑布局和浏览器插件1.0.9的验证及发布入口。

## 行为

- 原标签仍是简历资料 `library_fields.tags`，支持自由输入、原文展示与原条件筛选。
- 收藏夹为人工维护的个人或团队分类，独立使用 `folder_ids`、`folder_details` 与 `folder_id`，AI、采集、原标签不会自动创建或加入。
- 小型横向收藏夹栏显示人数、记住最近选择；管理弹框维护分类，删除仅解除关系。候选人编辑遇到不存在的收藏夹失焦时确认创建，默认个人；插件只能搜索选择已有收藏夹。
- 原标签列保留，表格新增独立收藏夹列；原行双击、备注与推荐行为保留。
- 企业招聘、猎头推荐、岗位管理去掉顶部标题和说明，查询、筛选、新增、刷新在同一行。侧栏去掉招聘设置，企业页内部入口改为弹框，共用旧设置路由的内容。
- 个人配置去掉页头标题和说明，保留保存与通知偏好；选项卡和各类配置放在同一个白色面板，取消整块AI绿色背景。
- Chrome插件1.0.9更新下载配置；Firefox1.0.9送审ZIP单独交付，现有签名1.0.7保留。现有Agent兼容配置整份保留。
