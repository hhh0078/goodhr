# 简历库与 Chrome 插件上线记录（2026-10-10）

## 本轮范围

- 参考 HiMatch 猎聘猎头端联系方式行读取方式，兼容完整号码后带“复制”等文字；只读当前候选人可见信息。隐藏、掩码和多个不同号码不猜测，保留手工补号。
- 招聘页面提供 GoodHR 悬浮入口，界面放在独立 Shadow DOM 和插件域 iframe 内，用户点击后展开。插件自身按钮可操作，招聘网站业务 DOM、焦点、滚动和按钮不由插件控制。工具栏/侧栏作为备用入口。
- 仅发布 Chrome 1.0.3。本轮不更新 Firefox 下载，统一版本与下载地址仍通过后台 `system.browser_extension` 维护。
- 每个已登录账号可查看管理员内置的“瓜瓜”示例。联系方式由用户明确指定，所在地四川成都；学校、公司、年龄及经历均标注为虚构。示例为虚拟只读资料，不写入真实候选人表，不参与真实统计、查重或岗位任务。
- 示例详情包含独立说明备注。修改、删除、追加备注、推荐、AI 摘要保存和其它写入入口拒绝内置身份；未登录不能访问示例或私人简历 API。
- 保留前期简历库紧凑界面、独立备注、推荐状态和历史、岗位横向切换、推荐显示偏好、头像保存、查重及人工确认更新。

## 安装与验收

从官网 `/download` 下载 Chrome ZIP，解压后在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”。已加载旧目录时，需要重新加载插件并刷新招聘页面。ZIP 是供手动加载的发布包，尚未通过 Chrome 商店自动安装。

打开候选人详情页或弹框，点击页面上的 GoodHR 入口，核对姓名、手机号和经历。页面没有显示号码时手工填写；不会自动购买或解锁联系方式。部分站点策略可能不允许嵌入插件 iframe，此时从浏览器工具栏或侧栏打开。

插件可用 GoodHR 邮箱密码/验证码手动登录。本轮没有另发本地 Agent；并行的下载导入功能已发布 Windows 6.2.10.3，升级后可使用其配对、AI 导入与摘要接口。自动登录仍需要用户确认账号配对；本轮没有使用真实账号验证自动配对。云端登录、简历库及插件手动入库可以独立使用。
