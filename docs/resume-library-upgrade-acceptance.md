## 头像补齐与参考细节核对

用户补充指出头像遗漏后，本轮补齐可见候选人头像读取、确认保存时下载、云端持久化以及列表和详情展示。头像源地址只留在插件临时快照；GoodHR 保存图片内容，不依赖招聘平台链接长期有效。普通预览不自动下载外部头像。

云端复用简历 `library_fields` 保存 `avatar_data_url`，随简历权限返回，不新增公开图片目录或对象存储依赖。原图最多 1MiB，先验证真实格式和像素尺寸，再等比缩至最长边 256px、剥离元信息；PNG 保留透明度，GIF 取首帧，最终内嵌 PNG/JPEG 不超过 128KiB。缺图、空值或读取失败保留已有头像。头像读取失败可单独重试，不重复创建简历。

图片域白名单沿用已核实的当前平台域、猎聘 `*.lietou-static.com` 和智联 `mypics.zhaopin.cn`。前程无忧首期仅同域头像，额外 CDN 需真实页面核实后扩充；实际图片重定向、登录保护和企业端选择器仍列入人工验收。
