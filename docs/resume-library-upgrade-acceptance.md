## 头像补齐与参考细节核对

用户补充指出头像遗漏后，本轮补齐可见候选人头像读取、确认保存时下载、云端持久化以及列表和详情展示。头像源地址只留在插件临时快照；GoodHR 保存图片内容，不依赖招聘平台链接长期有效。普通预览不自动下载外部头像。

云端复用简历 `library_fields` 保存 `avatar_data_url`，随简历权限返回，不新增公开图片目录或对象存储依赖。原图最多 1MiB，先验证真实格式和像素尺寸，再等比缩至最长边 256px、剥离元信息；PNG 保留透明度，GIF 取首帧，最终内嵌 PNG/JPEG 不超过 128KiB。缺图、空值或读取失败保留已有头像。头像读取失败可单独重试，不重复创建简历。

图片域白名单沿用已核实的当前平台域、猎聘 `*.lietou-static.com` 和智联 `mypics.zhaopin.cn`。前程无忧首期仅同域头像，额外 CDN 需真实页面核实后扩充；实际图片重定向、登录保护和企业端选择器仍列入人工验收。

## 真实采集验收

1. 在猎聘企业端独立简历页打开用户指定候选人，再在 `/chat/im#preview` 打开同一个候选人的详情弹框；分别点击 GoodHR 图标。无需登录插件即可查看本地读取结果。
2. 检查姓名、完整手机号、城市、年龄、学历、职位、期望、工作/教育经历及头像识别状态；页面未展示的值应留空，不猜号码。参数 `resIdEncode` 用于平台身份，保存的来源 URL 去除查询参数。配套服务更新后确认入库，再核对主库照片与原候选人一致；断开招聘页后，主库照片仍应可显示。
3. 切换候选人、关闭弹框，确认旧人的备注和岗位选择不混到新人；隐藏详情不能被采集。暂不支持第三方 iframe 内详情，多人同时可见时不猜测。
4. 其他平台按相同步骤分别验收；当前没有这些真实账号验收证据。
5. 先只看读取结果。使用云端新增、查重、登录、备注和推荐前，必须先更新配套后端、迁移和前端。当前线上旧接口登录返回 404，插件会提示先使用本地预览；这不代表手机号读取失败。

浏览器工具安全策略不允许进入 `chrome://extensions`，且当前招聘页 DOM 调试上下文不可用。本轮只通过可见页面确认目标简历存在，没有绕过限制，也没有把真实简历写入测试样本、仓库或云端。
