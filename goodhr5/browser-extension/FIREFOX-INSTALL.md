# GoodHR 简历助手 Firefox 版

## 安装方式

当前提供的是 Mozilla 审核签名的 Firefox XPI 正式包：

1. 从 GoodHR 下载页下载 `.xpi`，无需解压。
2. 打开 Firefox 下载记录，点击安装包并按浏览器提示确认权限。
3. 安装后点击浏览器工具栏里的 GoodHR 绿色图标，登录 GoodHR 或连接同账号的本地程序。

签名版在 Firefox 重启后仍会保留。GoodHR 本地程序也会在启动时校验并准备最新版签名插件，供 GoodHR 自带的 Firefox 自动加载。

## 使用方式

在猎聘企业端、猎聘猎头端、智联招聘或前程无忧打开候选人详情。插件识别到可见简历后，会自动展开简洁的入库卡片。手机号是入库必填项；页面没有完整手机号时，可在卡片里手动补齐。

Firefox 版与同版本 Chrome 版共用业务代码，功能一致：

- 自动读取当前可见简历，识别姓名、联系方式、城市、经历、教育和头像。
- 先按手机号精确查重，再按姓名、公司、学校和职位做模糊查重。
- 未入库时直接添加，已存在时提示选择并更新，不再多弹一次确认。
- 支持备注、岗位搜索与推荐记录，备注和推荐分别保存。
- 支持连接 GoodHR 本地程序生成 AI 总结，也支持账号密码或验证码登录。
- 支持“入库后自动关闭”，设置会保存在插件里。
- 发现新版本时强提示更新，并暂停旧版写入，避免新旧数据规则冲突。

## 数据边界

插件只读取当前页面中已经展示的候选人资料，并只增加自己的隔离卡片。它不会自动点击、购买联系方式、滚动页面、读取网站 Cookie，或修改招聘网站的业务内容。简历只有在你点击添加或更新后才会保存到 GoodHR；头像会在保存时读取并存入 GoodHR。

插件登录和本地程序连接放在工具栏弹窗里，候选人页面只显示本次简历相关操作。遇到识别不完整时，可以先补手机号或重新读取，不会在后台悄悄入库。
