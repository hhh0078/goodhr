# GoodHR 简历助手 1.0.4

本轮交付 Chrome ZIP，可解压加载；尚未发布 Chrome 商店，不能自动安装。Firefox 本轮暂缓分发，源码仍保留兼容实现。

## Chrome 安装

1. 解压 `goodhr-resume-chrome-1.0.4.zip`。
2. 打开 `chrome://extensions`，打开“开发者模式”。
3. 点“加载已解压的扩展程序”，选择含 `manifest.json` 的解压目录。
4. 将 GoodHR 图标固定在浏览器工具栏。需要 Chrome 116 或更高版本。

## Firefox 暂缓分发

旧版 1.0.2 ZIP / `unsigned.xpi` 仅作为历史开发资源保留，没有 Mozilla 签名，只能通过 `about:debugging#/runtime/this-firefox` 临时加载，重启后移除。当前新版下载入口仅提供 Chrome，Firefox 等单独验收后再分发。

正式 Firefox 安装需单独完成 Mozilla 签名。Chrome 正式公开分发需独立的商店流程。本版本不自动安装到 Agent / Camoufox，也不改变原来的招聘自动化。

## 登录和使用

1. 点击绿色 GoodHR 图标，工具栏弹窗只管理登录、账号、连接本地程序和一次数据用途授权。候选人资料与操作仅在招聘页浮窗中展示，未登录仍可在浮窗查看只读预览。
2. 用 GoodHR 邮箱密码或验证码登录。密码不会保存在插件。也可选择“本地程序已经登录？”：输入本地端口（默认 43129）并连接，在打开的 GoodHR 控制台确认一次。后续同一安装可以自动恢复已配对账号。
3. 打开猎聘企业端 `lpt.liepin.com`（含聊天页 `/chat/im#preview` 的弹框和独立页 `/resume/detail`）、猎聘猎头端 `h.liepin.com`、智联 `rd6.zhaopin.com`、前程无忧 `ehire.51job.com` 的候选人详情。可见详情被识别后，右下角自动展开简洁浮窗，补号、选岗位、写备注后直接点添加或更新。标题条可拖动，面板可收起；同一人收起后不反复弹出，换人自动展开。拖动仅调整插件自己的位置，限制在窗口内。
4. 悬浮区采用独立 Shadow DOM，里面是独立的简历操作界面，登录和配对设置不会放在招聘页中。只创建/更新插件自己的容器，不修改招聘页原有内容或样式，不自动点击、不滚动、不解锁联系方式、不购买手机号、不读招聘 Cookie、不拦截网络。工具栏仅保留账号与设置，不嵌入招聘页面。
5. 请检查姓名和手机。未识别到手机号、掩码或不完整号码都需补齐。支持完整中国大陆11位号（`+86` / `0086`规范化）及明确带`+国家区号`的7至15位国际号。输入始终保留；旧的无号记录可以先备注或推荐，添加/更新资料前需完整号码。
6. 登录并同意数据用途后自动查重。补号、改姓名或线索会防抖重查；也可点“查重”重试。精确结果和综合年龄、最早学校/公司线索显示实际依据与分组。仅唯一精确结果自动选中；多条或相似结果需自己确认，不自动合并覆盖。查重失败明确提示，保存前需重试。
7. 新人点击“添加简历”；已有候选人可独立“加备注”或“保存推荐记录”。更新只改主体，不顺带提交备注/推荐；直接更新并校验版本，不再弹第二次确认。未读到的字段、空值和空经历保留原内容；主动清空请到主简历库编辑。
8. 岗位加载完整列表，可搜索并选择已关联、已推荐、沟通中、面试中、Offer、已入职或暂停。推荐专属备注、推荐发生时间与候选人备注分开；时间留空用当前时间。记录显示作者、发生时间与状态变化，各自失败输入和幂等键保留，点对应按钮重试，不重建候选人或重复成功项。
9. 识别到头像时会提示“保存时一并读取”，未登录预览不请求第三方图片。点击保存后后台只从当前平台及猎聘 `*.lietou-static.com`、智联 `mypics.zhaopin.cn` 的有限图片域读取，拒绝重定向，不发送网站 Cookie。图片原文最多 1 MiB、最多 800 万像素，整理为最长边256像素的 PNG/JPEG，完整内嵌数据最多131072字符。WebP 在插件后台转换。头像失败不会清空已有头像，可单独重试，不重复创建简历或备注；保存成功显示 GoodHR 已存头像。

关闭弹窗后，本地草稿保留24小时、最多30份，按候选人和账号分开存放。同一人同一账号可恢复，切人/切账号不会串写。补读只更新未手改字段，备注和岗位输入保留；较长操作仍建议使用侧栏。退出会停止使用账号，并分别撤销云端会话和本地连接授权。本地程序离线或网络失败时，界面会明确显示“仍未撤销”，私有保存待撤销凭证，禁止自动恢复；重新运行本地程序后点“重试撤销旧授权”。后台在界面打开时也会间隔重试。撤销完成后连接本地账号需要重新授权。卸载前请先完成撤销，避免本地授权仍留在本地程序中。暂不支持第三方页面 iframe 内详情；多位详情同时可见时不猜测，收起多余详情后重新读取。

## AI总结与更新提示

“连接本地程序 / AI总结配对”始终可展开，手动登录后也能连接同账号本地程序。已有手动会话点击恢复时保留当前账号；本地批准账号不同会停止使用并撤销新授权，提示先退出当前账号再连接。同账号配对成功会撤销旧的手动会话。

“生成总结”明确调用一次本地程序配置的AI服务。结构化职业事实（公司、岗位、学校、经历、描述）会发送给该AI服务；请求移除姓名、联系方式字段、头像和来源编号，不读取招聘Cookie，不借用完整网页登录Token。插件云端只存数据，不执行AI。任务可查看进度、取消；失败不自动重新生成，可能已计费时明确提醒，重试需确认。摘要先存本地草稿，确认后点“保存总结到已有简历”，仅PATCH摘要并校验版本，失败可独立重试。

总结完成后，再次明确点击会使用新请求编号，允许修改职位后生成新稿。失败/取消且资料没变化时用原任务明确重试；职业事实已改时出现“按当前资料重新生成”，确认后用新编号。首次响应未知时保留原编号和去联系后的职业资料快照，点“查询上次总结”只用原资料恢复，不重复AI；确认原任务结果后才允许新稿。草稿按实际UTF8总量最多3MiB、最多30份，优先当前候选人并清理较旧记录；冻结总结职业资料单份最多1MiB。草稿24小时内可恢复，过期下次访问清理。存储失败会提示“本地草稿没保存”，输入仍在当前界面，先别关闭，修改后可重试。

选择岗位默认只是“已关联”，需要你明确选择其它状态后保存，才记录推荐推进。

插件从公开配置`GET /api/system/browser-extension`检查版本。发现更高版本后，工具栏与浮窗显示醒目的更新块，点击“立即更新”前往官网下载页。旧版的添加、更新、头像、备注、推荐与AI生成/保存均在后台阻止；本地预览、查重、记录读取和取消既有AI任务仍可使用。版本检查一分钟内复用，已知更新要求私有保留，网络失败或后台重启不会抹掉；重新加载达到所需版本的插件后恢复。浏览器开发包无法自动安装，需下载并重新加载。插件内Alt+Enter可添加当前已确认新人；快捷键只在插件自身界面（含扩展域悬浮面板）生效，不监听招聘业务页面的键盘。

## 采集字段

仅读取当前可见候选人的姓名、完整手机号、邮箱、年龄/性别、城市/学历/职位/求职状态和可见经历。页面未显示的字段留空，薪资保留原文字，避免把年薪误当月薪。原始页面、截图、网站 Cookie 和隐藏节点不上传。

各平台会调整页面结构。当前适配依据仓库已有选择器和参考项目源码；新页面或缺字段时可人工补齐并到简历库编辑。不代表已用真实招聘账号完成全部页面验收。未发现候选人时可刷新招聘页面、检查是否已授予该站点访问权限，再点击“重新读取”。

企业端头像只使用明确候选人区域兼容选择器，仍待真实页面核实；前程无忧目前仅同域图片，参考清单未发现额外图片 CDN 证据。图片域不支持或头像未识别时，可先保存其它资料，稍后重新读取后重试。参考猎聘插件本身没有证书/荣誉解析，本插件不猜测这些选择器；智联保留已有明确证书读取。已存在候选人可点击“查看完整简历”打开 GoodHR 详情。

本地程序尚未升级时，首次配对接口不可用，请使用手动登录。网络失败请检查当前连接；手机号或版本冲突请重新查重。不要为插件授予所有站点权限。

插件登录提示 404 时，表示当前 GoodHR 服务还没有更新插件登录接口，可先用未登录的只读预览，服务更新后再登录。插件不会伪造登录或借用网页登录凭证。

## 本地构建与测试

无需安装依赖：在 `goodhr5/browser-extension` 运行 `npm test`、`npm run build:chrome`。本轮输出在 `dist/chrome` 和 `goodhr-resume-chrome-1.0.4.zip`；版本只取 `package.json`，与本地 Agent 版本相互独立。`dist/checksums.json` 记录 SHA256。默认 `npm run build` 仍保留双浏览器开发构建能力，不代表 Firefox 已发布。本地构建测试使用独立忽略目录，不改已有 `dist-local` 测试包。

`node scripts/export-create-fixture.js` 会从合成输入通过实际插件整理器导出 `tests/fixtures/plugin-candidate-create.json`，供云端 Go 路由测试直接验证。标签为文字数组，地区使用 `current_region` / `expected_region`；明确数值薪资单位为 K，页面原文字单独保存。该文件和企业端嵌套预览 fixture 均不包含真实个人资料。

已有仓库前端 Playwright 和本机 Chrome 时，可运行 `npm run test:ui` 做插件本地界面假接口验证。该验证不访问招聘网站、不登录真实账号，截图写到忽略目录 `artifacts`。缺浏览器时不自动下载，请使用已经安装的 Chrome。

`npm run test:extension` 在独立Chrome临时配置中，通过官方扩展调试协议加载测试构建，以合成招聘页面验证扩展iframe实际消息来源和未登录预览。仅允许这次合成页面与扩展静态资源，其它网络阻断；不使用现有浏览器配置或登录，结束清理临时目录。请先运行`npm test`准备隔离测试构建。本轮Chrome154实测sender.tab指向对应详情页、frameId为子框架；浮层无需网页postMessage或额外页面授权秘密。
