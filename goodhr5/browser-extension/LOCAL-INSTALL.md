# GoodHR 简历助手 1.0.2 · 本地测试

本包名称带“本地测试”，简历业务只连接 **http://127.0.0.1:8084**，网页入口只打开 **http://127.0.0.1:5173**。不连接生产 GoodHR，也不支持自行替换服务器地址。请先启动本地 Docker 的测试后端和网页，再使用测试库账号登录；生产账号和浏览器里的生产网页登录不会自动搬过来。

招聘页面仍使用已登录的猎聘企业端、猎聘猎头端、智联、前程无忧页面。读取范围、只读限制和有限头像域与普通版本一致。手机号补填、自动查重、添加、更新、备注和岗位记录都写入本地测试库。读取真实候选人后，请确认确实需要保存；调试建议使用合成资料。

## 安装

运行 `npm run build:local`，无须安装依赖。产物在 `dist-local`；普通 `npm run build` 仍输出原来的 `dist`，不会把本地地址打进正式包。

- Chrome：打开 `chrome://extensions`，打开开发者模式，点“加载已解压的扩展程序”，选择 `D:\work\goodhr-plugin-local-test\chrome`，或解压 `goodhr-resume-chrome-local-1.0.2.zip`。需要 Chrome 116 或更高版本。
- Firefox：打开 `about:debugging#/runtime/this-firefox`，点“临时载入附加组件”，选择 `D:\work\goodhr-plugin-local-test\firefox\manifest.json`，或 `goodhr-resume-firefox-local-1.0.2-unsigned.xpi`。需要 Firefox 140 或更高版本；未签名，重启后需重新临时加载。

本地 Firefox 使用独立附加组件编号，与普通版本的账号、配对和草稿存储分开。Chrome 请从独立的本地目录加载。为免点错图标，测试时可暂时禁用普通版，**不要选择旧的正式测试目录**。重新构建或复制后，在扩展管理页重新加载插件；已打开的招聘页面可手动刷新，让内容脚本更新。

## 配对与AI总结

本地测试程序端口默认 **43139**；请使用独立测试 Agent，不要连接正在使用生产账号的普通程序。首次连接会打开 `http://127.0.0.1:5173/admin/resumes` 确认授权；本包会拒绝生产网页或其它地址的授权链接。测试网页需登录与插件相同的本地账号。

测试 Agent 需另行手动启动。只启动 Docker、43139 尚未运行时，邮箱登录、采集、查重、保存仍可测试；配对和AI总结暂时不可用，不会回退连接生产程序。

未登录也可在插件中查看当前候选人的中文预览和重新读取。查重及保存需登录并同意数据用途；退出时会分别撤销测试会话和本地配对，撤销失败保留待重试状态。

“生成总结”会调用测试 Agent 配置的AI服务商，职业资料会交给该服务商，**仍可能产生费用**。仅需要检查采集、查重、入库时可跳过总结。摘要明确保存后才进入本地测试库。

## 遇到问题

- 登录或查询连不上：确认本地 API 在 `127.0.0.1:8084`、网页在 `127.0.0.1:5173` 正常运行。不要改用生产地址兜底。
- 配对失败：确认独立测试 Agent 运行在43139，且插件、测试网页和程序使用同一测试账号。
- 插件没有发现简历：打开可见的候选人详情或聊天简历弹框，再点“重新读取”。未展示的资料不会猜，缺手机号可手工补填。
- 本地测试包没有商店发布或 Firefox 签名，不能当作正式安装包。正式版本的源码、安装说明和ZIP内容保持原样。
