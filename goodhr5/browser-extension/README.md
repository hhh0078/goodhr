# GoodHR 简历插件 1.0.13

安装方式见 [Chrome 安装说明](INSTALL.md) 和 [Firefox 安装说明](FIREFOX-INSTALL.md)，数据用途见插件中的“数据说明”。

BOSS 仅支持当前候选人主动打开的附件 PDF。插件只读取可见同源文字层，不读取隐藏 Vue/PDF.js 状态，不截图或 OCR，不自动滚动。扫描件没有文字层时跳过；发现缺页时等待手动加载。

文字稳定后自动识别基础资料，并复用已有查重流程。当前账号未配置 AI 时只提示设置，不切换供应商。点击添加或更新会冻结当时的人工核对字段、收藏夹和写入目标，并把可信附件全文提交到服务端保存任务。新建时携带当时的备注和岗位推荐；更新不隐式保存这些独立记录。

界面收到任务回执后显示“已交给后台处理”。服务端完整解析并自动入库，完整结果不返回插件界面；关闭卡片、切换候选人不影响已受理任务。网络结果未知时保留原请求编号，优先查询原任务，重投仍使用原编号和冻结输入，避免重复 AI 调用。

重新识别、重试总结或失败后重新核对，会先在卡片内确认可能再次计费。取消、切换候选人或账号、收起卡片都不会放行这次新请求；已经交给后台的保存任务照常继续。

明确尚未受理的重复资料、版本或配置错误，会保留人工输入并重新查重；已经受理的失败任务可在确认可能再次计费后重新核对，原任务仍可查询。部分成功只查看已存简历并处理未完成记录，结果未知只查询原任务。旧版完整解析先查询，完成时复用；进行中不另发 AI，失败或未知需明确确认成本。

头像仅从当前唯一附件内的独立可见图片保守筛选，多个合理候选无法区分时留空。没有独立图片地址时跳过，不把 PDF 整页画布当头像；不增加图片代理、服务器抓图或 AI 图像调用。

运行 `npm test` 验证合成场景；运行 `npm run build` 生成同版本 Chrome 开发包和 Firefox 未签名临时包。未签名 Firefox 包不能当成正式签名安装包发布。

本次独立交付 `goodhr-resume-chrome-1.0.13.zip`、`goodhr-resume-firefox-unsigned-1.0.13.zip` 和同名 `.xpi`。Firefox 1.0.13 未签名包仅供 `about:debugging` 临时加载测试；不覆盖已有 1.0.9 签名包，不冒充正式自动更新版本。Mozilla 签名完成前，Firefox 正式发布版本由服务器现有签名配置维持。
