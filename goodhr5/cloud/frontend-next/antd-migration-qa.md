# Ant Design 迁移与验证记录

本文件记录 2026-10-09 前端组件迁移的范围、验证入口和实际测试边界。

## 迁移范围

- Next.js 前端移除 MUI、原有 Emotion 样式方案与 `sx`，使用 Ant Design 6.6.5、中文语言包及官方 Next.js SSR Registry。Ant Design 自身依赖的 `@emotion/hash` 等基础包正常保留。
- 后台的表格、表单、数值/日期输入、选择卡、消息、菜单、抽屉、弹框和图片预览使用 Ant Design。
- 保留会员主题、原有接口及云端与本地程序的职责。同步主分支的完整 AI 诊断展示和日志复制功能。
- 岗位置顶小窗使用 Ant Design 组件，独立窗口单独注入组件样式，保持 340×250px、运行状态、AI 转圈和结果展示。
- 微信支付使用 Ant Design 原生 SVG 二维码，保留 H 级纠错、微信图标、黑白对比和手机适配；移除原 `qrcode.react` 依赖。
- 同步 npm 与 pnpm 锁文件，保留 Docker 原有的国内镜像和 `npm ci` 安装方式。
- 官网继续采用独立 HTML/CSS 排版和服务端输出，保留正文、元信息、JSON-LD、站点地图、robots、llms 和旧地址重定向。
