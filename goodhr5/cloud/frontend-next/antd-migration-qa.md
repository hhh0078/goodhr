# Ant Design 迁移与验证记录

本文件记录 2026-10-09 前端组件迁移的范围、验证入口和实际测试边界。

## 迁移范围

- Next.js 前端移除 MUI、原有 Emotion 样式方案与 `sx`，使用 Ant Design 6.6.5、中文语言包及官方 Next.js SSR Registry。Ant Design 自身依赖的 `@emotion/hash` 等基础包正常保留。
- 后台的表格、表单、数值/日期输入、选择卡、消息、菜单、抽屉、弹框和图片预览使用 Ant Design。
- 保留会员主题、原有接口及云端与本地程序的职责。同步主分支的完整 AI 诊断展示和日志复制功能。
- 岗位置顶小窗使用 Ant Design 组件，独立窗口单独注入组件样式，保持 340×250px、运行状态、AI 转圈和结果展示。
- 微信支付使用 Ant Design 原生 SVG 二维码，保留 H 级纠错、微信图标、黑白对比和手机适配；移除原 `qrcode.react` 依赖。
- 同步 npm 与 pnpm 锁文件，保留 Docker 原有的国内镜像和 `npm ci` 安装方式。
- 官网继续采用独立 HTML/CSS 排版和服务端输出，保留正文、元信息、JSON-LD、站点地图、robots、llms 和旧地址重定向。

- `pnpm test:ui`：最终生产预览 20 组浏览器测试全部通过（2.3 分钟），包含岗位/会员/支付/个人配置 59 项交互、其他后台业务 24 项交互、真实独立置顶窗口 15 项交互，共 98 项业务检查。
- 弹框重点验证：取消、Escape、遮罩、草稿保留、校验、提交期间关闭与重复提交锁、必要更新、密码补设、嵌套图片预览及手机长表单。

- 置顶窗口验证零分、长原因、加载动画、开始/停止、手动关窗不中断岗位及重新打开；独立窗口组件样式正常。

## 复跑方式

在此目录运行 `pnpm test`、`pnpm build` 和 `pnpm test:ui`。浏览器测试默认使用已安装的 Chrome，并自动启动本机 5190 端口的开发预览。测试生产预览时，可通过环境变量 `UI_TEST_BASE_URL` 指定已有的本机预览地址。

可复用测试位于 `tests/ui/ant-design.spec.ts` 和 `tests/ui/flows/`。截图和交互记录保存在已忽略的 `artifacts/`，失败跟踪保存在 `test-results/`。

## 实际边界

所有浏览器业务接口均使用模拟数据，支付、退款、验证码、密码保存、团队和岗位修改未操作真实账户。测试覆盖页面交互与请求内容，真实支付到账和真实招聘平台操作仍需相应环境验收。npm 验证在 Windows 独立目录中完成，未构建 Docker 镜像；本任务未部署生产站点。

## 2026-10-09 布局与交互补充修复

- 官网、登录和后台常规按钮统一胶囊圆角，输入框和卡片继续使用原有小圆角。
- `AdminDialog` 的取消、确认和额外操作统一靠右，手机换行时每行也靠右；保留提交期间关闭及重复提交保护。
- 全局 `ConfigProvider` 为选择框开启输入筛选，同时匹配标签、旧 `Select.Option` 内容和选项值。模型选择继续支持名称和模型 ID。
- 简历搜索输入、岗位选择和按钮统一 38px 高，按钮按内容宽度。列表采用固定列宽和原生两行省略，长邮箱、分析和备注不再撑高整行，全文可在提示、备注弹框和详情查看。
- 简历详情在桌面分栏、手机上下排列；长经历和分析正常换行，完整原文在 420px 区域内滚动，完整接口数据仍可展开查看。
- AI 余额卡按内容宽度排列，长模型名称省略并保留全文提示，手机自动换行。
