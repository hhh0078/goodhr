# Boss 滚动诊断与窗口调整开发清单

更新时间：2026-07-23

## 目标

- 下次出现“候选人卡片不在当前页面”时，仅凭岗位日志和 `browser-worker.log` 就能区分主要原因。
- 将自动化浏览器固定内容视口从 `1280×720` 调整为 `1440×900`，让 Boss 候选人列表显示更多内容。
- 不改变真实鼠标滚轮操作方式，不通过 JavaScript 直接推动页面滚动。
