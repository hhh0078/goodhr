# Boss 滚轮安全边距修复开发清单

更新时间：2026-07-23

## 目标

- 候选人列表滚动时，只把鼠标移动到完整处于上下安全边距内的候选人卡片。
- 锚点卡片不在安全区域时立即换一张卡片，不再把鼠标移动到不可交互区域。
- 在 `browser-worker.log` 中记录锚点选择、拒绝原因、安全区域和最终鼠标落点。
- 保持真实鼠标滚轮操作，不使用 JavaScript 直接推动页面滚动。
