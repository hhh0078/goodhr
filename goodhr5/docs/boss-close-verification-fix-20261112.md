# BOSS 关闭详情误停及相似问题修复

2026-11-12。用户确认修复 Windows 6.3.4 在王雷详情关闭后的误停，并检查 BOSS 中的相似问题。

## 原因及修改

- 原诊断的北京时间 11:41:12 已打开王雷详情，11:41:40 完成 AI 分析并以 90 分通过，11:41:41 执行 Esc。关闭检查的父级预算只有 1000 毫秒，Worker 实际预算 900 毫秒；检查超时被包装为 `WORKER_UNRESPONSIVE`，岗位停止。11:41:43 再次探测只用 266 毫秒，确认详情已经消失。本次没有进入王雷的打招呼步骤。
- `internal/platform/common/detail.go` 移除 Esc 验证专用的一秒子期限，改为最多四次状态复查，不提前取消正在进行的单次读取。整体候选人取消、任务期限和 Browser Client 原有请求上限仍有效；真正的浏览器故障继续返回，不能以弹窗可能已关为理由放行。
- `internal/platform/common/runtime.go` 复用原有隐藏检查方法，以明确的复查次数区分快速关闭检查和正常关闭动画检查。每次读取前后都检查任务取消，不读取被销毁节点的正文，不新增 Worker 能力或平台专属公共分支。
- 同时修复详情备用关闭按钮的两个结果竞态：按钮回执异常但弹窗实际已关，以及检查关闭按钮时弹窗刚好消失。先复核弹窗状态，确认消失才成功，禁止多按 Esc 或盲目补点。
- 同时修复 BOSS 主动招呼复用的聊天框、联系人侧栏关闭流程：非会话故障的点击错误后，先核实面板是否消失，再决定是否补点。真正断连、检查故障和任务取消仍中止。此修复位于共享关闭方法，因此其余平台调用相同方法时也保留同一套状态确认规则。
- 排查了 BOSS 的详情打开、推荐页聊天与联系人收尾、自动回复的一键收起、附件预览，以及对应的共享关闭和 Worker 点击验证。自动回复的 Esc 关闭已逐次核对原页及身份，Worker 点击验证在同一请求内读取状态，没有发现另一个相同的一秒验证子期限。本次不更改它们的流程或发送规则；附件整体清理预算及真实任务期限保留。

## 验证

- 新增回归用例在原始 `detail.go`、`runtime.go` 的 Go overlay 下失败：超过一秒的正常关闭检查被误判、备用按钮关闭结果报错、聊天框和联系人侧栏已关后仍补点。相同用例在修复后通过。
- `go test ./...` 全量通过。覆盖实际任务到期不再追加动作、浏览器故障不被掩盖、面板仍在时保留关闭失败，以及原有 Esc 备用按钮行为。
- 使用正式 Go Browser Client、原有 TypeScript Worker 和本机 Camoufox，在独立临时 Profile 的本机测试页面运行 `TestBossDetailCloseExistingWorkerLayouts`。当前布局、旧主页面布局、旧内嵌布局各测试 Esc 生效和 Esc 无效后的备用关闭，共六种情况全部通过。三个 Esc 生效场景在按键后人为增加 1100 毫秒的只读调用延迟，仍正确确认隐藏，且无备用点击。此延迟位于测试包装器，不向招聘页面注入脚本。
- 初次隔离测试因测试入口约定根目录 `addons/UBO` 而本机 Mac 资源位于 `.app/Contents/Resources/addons/UBO`，在启动前失败。仅在 `/tmp` 建立本次测试用资源路径链接后重新运行，六种情况通过；没有修改已安装浏览器、用户 Profile 或业务数据。测试自行关闭独立进程和本机标签页。

## Windows 与 macOS

- 正式修改全部在公共 Go 平台能力中；Windows x64、macOS arm64 和 macOS amd64 使用同一份状态检查，无系统专属调用，无新依赖。实现位置为上述两个共享文件；BOSS 仍由 `internal/platform/boss/detail.go` 调用，选择器仍由本地 BOSS 配置提供。
- `CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build ./cmd/goodhr-local-agent` 通过。
- `CGO_ENABLED=0 GOOS=darwin GOARCH=arm64 go build ./cmd/goodhr-local-agent` 通过。
- `CGO_ENABLED=0 GOOS=darwin GOARCH=amd64 go build ./cmd/goodhr-local-agent` 通过。
- Mac 本机已完成隔离浏览器和正式关闭方法回归；没有在真实招聘页面联系候选人，也没有运行完整 AI 招呼任务。Windows、Intel Mac 的真机运行和三个目标的安装包安装尚未验证。
