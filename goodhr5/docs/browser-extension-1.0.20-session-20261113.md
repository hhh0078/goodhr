# 插件1.0.20：使用时续满30天

## 行为

- 云端插件专属会话由7天改为30天，新登录、配对签发和续期复用同一期限。
- 打开插件界面或调用云端业务前，尚未过期的登录自动续满30天。例如第29天使用后，再获得30天，下一轮仍可继续续期；五分钟内的连续操作复用刚续期的凭证。
- 尚有效的旧7天凭证可在使用新版时升级为30天；已经过期、被退出或撤销的凭证不会恢复，需重新登录。
- 续期只有收到明确401时才清理当前同账号、同凭证的登录。网络断开、超时和服务错误保留登录，业务可重试；账号页和草稿仍可打开。
- 沿用现有受限续期接口、并发合并和账号代次保护，未新增接口、权限、招聘页面操作或数据库迁移。
- 必须同时更新云端后端和插件。旧插件仍只会在401后续期，单独调整云端期限不能让旧插件自动滚动续期。

## 验证

- 修改前新增的4组插件回归检查均失败，证实缺少主动续期及临时故障误清理。
- 修改后插件完整`npm test`：177项通过，含真实Chrome加载扩展及合成页面检查。
- Go认证与插件会话相关测试通过，包含连续两轮第29天续满30天、过期拒绝、原凭证消费一次、退出和并发保护。
- 回归覆盖旧7天升级、同时操作只续一次、网络和500错误保留账号、恢复后重试、明确过期后清理。
- 所有浏览器验证均使用本机合成数据，未登录真实招聘账号、保存真实简历或发送招聘消息。
