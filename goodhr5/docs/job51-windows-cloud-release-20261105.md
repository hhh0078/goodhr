## 前程行为与实测

搜索页开始时只等待和读取既有候选名单，不自动选岗位、不填写关键词、不改变人才筛选。任务岗位名仅保存在 Go 平台运行时。招呼按钮只点一次，只有实际出现已识别的原生职位选择层时，才在该层搜索完整任务岗位名；唯一同名选项才可选，异步回显一致且目标稳定编号卡片显示“继续聊聊”才记成功。推荐页原选岗逻辑保留。

前程原生职位层点击岗位后直接收起，没有额外确认按钮。选择器仅在本地 `job51/config.json` 中，公共主流程、Worker 和云端不加入平台页面规则。读页、点击、键盘和滚轮均经现有 Camoufox/Worker 标准能力，无页面脚本注入。

用户授权下在独立标签实际招呼两位：有预选职位和“不限岗位”各一次，同一稳定编号卡片均转为“继续聊聊”，账号没有自然触发自动选岗层。平台在“不限岗位”时可能沿用上次沟通职位，本次未改变用户要求的“没有弹框就不主动选岗”规则。随后手动展开本次会话的原生职位层，调用正式 `selectGreetingJob` 搜索并选中“高级软件工程（半导体）”，真实回显延迟数轮后核对成功。自动出现职位层的完整流程以模拟状态机验证，不能称为真实账号已自然触发。

搜索条件仅由验收人员在临时标签手动准备，正式准备方法已验证不修改条件。测试曾因下拉项尚被滚动容器裁剪而误开候选详情，未追加招呼；截图确认并真实滚轮露出选项后完成手动准备。临时标签关闭，原标签保留；候选信息、截图和临时实测入口只保存在本机验收目录，不进入 Git。
