# 推荐页完整卡片起跑与Mac 6.3.3.8

2026-11-12。按用户修正，BOSS不能从仅露出边缘的卡片开始；并扩展到智联和无忧的无限滚动推荐页。猎聘企业需要另行核对真实样式，本次按用户允许的范围暂缓，没有改其配置或行为。

## 修改结果

- 原判断只要求卡片与屏幕相交，露出一个边缘也会被选中。现在先排除顶部被遮挡的卡片，再检查上下左右四边完整位于推荐页可用视口。若同一行首卡过高或横向裁切，继续只读检查当前屏幕内的后续完整卡片，不向下滚动寻找。
- 起点定位共用 `common.StartCandidateViewport`，平台只负责启用模式和配置可用范围。BOSS、智联、无忧的固定顶部遮挡分别是100、120、200 CSS像素，均通过当前真实页面截图和标准边界读数核对。视口大小来自原生Page/Locator，不写死屏幕尺寸；起点范围与后续操作避让分开。
- 无忧原有操作避让216/288保持不变。这两个值不能直接当作当前屏幕的完整卡片边界，否则会把真实完整卡片误判为空。本次为起点单独配置200/0，没有修改后续点击、滚动、详情或索要逻辑。
- 只有本地配置明确开启、名单模式为无限滚动、且当前URL属于推荐入口时，才跳过旧断点库。智联和无忧的搜索页明确排除，继续保留既有分页与正常断点；未启用的平台默认不改变。BOSS仍不接入历史断点，三个平台不回补失败者的6.3.3.7规则保留。
- 智联、无忧在正式页面初始化时确定推荐/搜索模式，首次名单读取才设置起点，后续批次不会反复重置。没有完整卡片、读取失败或位置变化时明确提示调整或等待页面，不降级点击残边、不默认为第0人。
- 原始行号和同名同龄定位计数保留，前方仅读取最小身份字段，不分析、不联系、不回补前方人选。所有读取和测试布置滚轮都通过既有Go Browser Client和标准Worker能力；没有页面JS注入、Worker平台分支或新增依赖。
