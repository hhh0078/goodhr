# 当前完整卡片起点与Mac 6.3.3.9

2026-11-12。用户反馈智联推荐、无忧推荐和无忧搜索仍未从当前页面第一张完整卡片开始。本次补查实际任务准备顺序，并明确将无忧搜索纳入当前视口起点。

## 原因与修改

- 智联推荐的 `SelectPosition` 原来每次都会重新选岗，即使已经是同一个岗位，也会刷新推荐名单，前面保留的屏幕位置因而失效。真实页面确认当前激活岗位标题节点有完整文本，省略号由CSS显示产生；现在只忽略空白和大小写核对完整名称，一致时不再打开选岗层。括号内容不同、实际截断文字或无法确认时，继续原切岗流程，不把相似岗位认成同一岗位。
- 无忧搜索在6.3.3.8仍被明确排除在视口规则之外，因此实际会走旧断点。现在由无忧本地配置 `candidate_search_from_viewport` 单独启用；当前页从首张完整卡片开始，后续正常分批、翻页，不重新定位旧断点。
- 无忧推荐在本机当前同岗位页面未再次复现跳回顶部，不能把尚未证实的原因写成定论。本次将完整卡片定位放到正式打招呼流程统一入口：打开、初始化、选岗、基础筛选全部结束后，首次扫描前确定一次游标；删除各平台缓存的初始化布尔状态，避免起点分散在平台首次读取中。无断点接口、无历史存储时也执行起点规则；后续批次不重置。
- 新增起点行号和首次候选人进度提示，便于核对页面与任务。继续不回补失败者。猎聘企业、智联搜索既有方式不变。未修改任何平台的发送、索要资料、详情点击或后续滚动逻辑。
- 完整卡片继续要求四边位于可用视口，不允许只露出边缘或被固定页头挡住。无忧搜索真实页面存在最小宽度：当前1280CSS像素窗口会横向裁掉右边操作区。这种情况下明确停止并提示拉宽/拉高窗口或调整列表，绝不退回列表开头。验收通过的是展开窗口后的完整卡片；窗口尺寸已还原。
