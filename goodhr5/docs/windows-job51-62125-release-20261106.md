# Windows 6.2.12.5 可选更新

本轮仅发布 Windows 本地程序和更新记录，不切换云端前后端、不修改 Mac 安装包。构建来源是最新 dev `258db45502c0a081be0aada33c1ce617c8e9f035`；main 与 dev 职责继续分开，不把开发分支整包合入正式云端。

## 本次内容

- 前程岗位启用索要简历后使用原生“邀投递”，检查邀请结果及既有邀请，失败不自动重发。
- 前程详情、聊天、会话切换和异常清理关闭后，使用同一包内新版 Worker 将鼠标移到页面中央，避免悬浮层遮挡。
- 关闭点击和移鼠标通过可选 `move_to_center_after_click` 协议一起交付；旧请求默认不移动，其他平台行为保留。没有新增依赖、平台专属系统调用或招聘页面脚本注入。
