# 智联排版定位修复

6.3.4.7在智联推荐页按姓名、基础信息和教育经历联合定位，避免名单换位后沿用旧行号。该实现把innerText产生的排版换行转为空格，但标准Locator的hasText读取节点拼接文字时不一定包含这些空格，造成第一位筛选通过后即可找不到原卡片。

6.3.4.8仅在此唯一身份选择器上开启`text_layout_whitespace`。Worker以转义后的完整文字片段按原顺序匹配，片段之间允许零个或多个排版空白；不删除姓名、经历等身份字段，不回退旧行号，不从歧义结果中默认选择第一位。未开启选项的所有旧选择器保持原匹配规则，智联搜索页、BOSS、无忧与猎聘平台配置未变。

通过Go平台配置、唯一Worker和标准Locator，在独立Profile中运行无脚本的真实Camoufox合成页。平铺、块布局、flex布局分别对照6.3.4.7的失败；修复后可定位、换位后仍定位原人选、同名不同学校可区分、完全相同身份拒绝。单元测试另覆盖空白变化、片段顺序、文字变更、正则字符转义、参数非法类型和旧请求省略字段。

实现属于公共Go协议和Worker标准定位，Windows amd64、macOS arm64/amd64共用，没有新增系统专属调用。Windows在原生CI打包，Mac在本机生成含双架构的通用包。合成页在Mac Apple Silicon执行，不等于Windows/Intel真实账号长跑；当前没有智联测试账号。

本次不处理BOSS悬停失败，不改点击、滚轮、截图及发送保护。6.3.4.8沿用第四段可选补丁规则。
