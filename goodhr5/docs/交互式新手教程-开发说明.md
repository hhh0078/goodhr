# 控制台交互式新手教程

## 用户体验

首次进入先邀请用户参加，支持开始教程或声明自己无需教程。跳过需完整输入 `让开，我不需要教程`，只保存当前账号在当前浏览器的选择。

教程分为五个阶段：准备本地程序、登录招聘平台、创建岗位、筛选并开始、看到筛选结果。顶部显示真实完成进度和剩余时间区间；安装下载速度、平台登录和 AI 等待会影响实际耗时，时间不是倒计时。

每个实际操作单独使用 Ant Design Tour 遮罩及说明，保留目标交互，完成后自动前进。提供上一步、稍后继续和遇到问题，不提供绕过业务检查的下一步。阶段完成给予简短鼓励与礼炮；减少动态效果设置会关闭礼炮。

新手创建岗位只显示名称、筛选模式、详情识别模式及适用条件。基础或详情任一使用 AI 时需岗位要求；关键词筛选需关键词；关键词配合 AI 详情时两项都需填写。原有完整新增和编辑表单继续用于普通使用。

## 状态和完成事实

- 界面进度：`lib/onboarding-state.ts` 使用版本 2 的账号隔离 localStorage；恢复页面后重新检测当前环境及岗位是否仍存在。
- 岗位草稿：`lib/onboarding-position-draft.ts` 只保存六项核心字段，按账号隔离，真实保存岗位成功后清除。
- 业务事件：`lib/onboarding-events.ts` 连接现有岗位保存、启动和筛选结果，通知异常不能影响业务操作。
- 云端事实：沿用 `/api/user-flow` 和现有存储结构，增加 `first_screening_result`，返回 `tutorial_completed`。历史已经完成的用户仍兼容；无需新建表。
- 真正完成：只有 AI 或关键词的终态筛选结果才算完成，接受或拒绝都可以；扫描数量、AI 分析中、关键词通过但仍需 AI 的预判断均不算完成。
- 本地程序：通用流程后台同步终态事实，只发送种类、阶段和终态标记，不上传候选人资料。同步有独立三秒上限，在途请求不叠加，失败允许后续真实结果重试，不阻塞招聘流程。

数据库事实优先于本机缓存。缓存不可用时当次仍可继续，并提示刷新可能无法保留位置；不同账号不会继承进度、草稿或请求去重。旧账号请求的迟到 401 不得清除新账号凭证。

## 弹框协调

教程活动中以及稍后继续状态，暂停公告、普通更新、关注奖励和新用户福利自动弹框；退出教程后恢复普通规则。必要升级与强制组件安装仍执行现有检查，邀请完成后让出遮罩，必要处理结束自动继续教程。连接失败由教程当前步骤说明和帮助承接，避免两层遮罩争抢。

遮罩目标使用控制台稳定的 `data-onboarding` 属性；等待弹框动画和目标出现后定位。菜单高亮整个真实菜单项；短窗口下将被正文裁切的字段滚入自身弹框的可视区域，捕获内部滚动并重新测量孔位，避免沿用旧坐标。窗口尺寸变化时重新定位。教程不向招聘网站注入脚本，不改变浏览器操作工具职责。

## 本机验证

验证使用三个独立本机端口：前端 5173、真实 Go 云端 8084、教程 Agent 协议模拟 43130。云端使用隔离内存存储，不配置 PostgreSQL、Redis 或 SMTP；验证码由开发邮件器提供，不向真实用户发信。

`tests/fixtures/onboarding-agent.mjs` 仅代理本机云端并补充内存环境缺少的平台及下载元数据；组件安装、更新、招聘登录与候选人结果使用协议模拟。不会下载真实安装包、启动招聘浏览器或发送招呼。用例限制允许的本机地址并拒绝正式 Agent 端口 43129 及外部请求。

从前端目录可执行：

```powershell
pnpm test
pnpm exec tsc --noEmit
$env:NEXT_PUBLIC_CLOUD_API_BASE = 'http://127.0.0.1:43130'
$env:NEXT_PUBLIC_LOCAL_AGENT_PORT = '43130'
node tests/fixtures/onboarding-agent.mjs
# 在另外的本机终端启动前端，云端需预先以隔离内存模式启动。
pnpm dev
$env:UI_TEST_BASE_URL = 'http://127.0.0.1:5173'
pnpm exec playwright test tests/ui/onboarding-api.spec.ts tests/ui/onboarding-flow.spec.ts
```

后端检查 `go test ./internal/httpapi`；本地程序检查 greeting、shared、cloud 与 lifecycle 相关包，并分别交叉编译 Windows amd64、macOS arm64 和 macOS amd64。Windows 上的模拟测试及交叉编译不能代表 Mac 真机安装、权限或招聘网站实测通过。

本轮不发布生产服务或本地安装包。正式本地程序发布前，仍需按已有发布规则生成 Windows/Mac 包并在对应系统验证。
