# 内置 AI 恢复主站域名

用户于 2026-11-27 确认主站已停用 CDN，内置 AI 统一恢复为 `https://goodhr.58it.cn/api/ai-compatible/v1/chat/completions`。

## 修改范围

- 代码默认值、系统默认和个人配置使用主站地址；接口路径、密钥、模型、温度、提示词及启用状态保持。
- 新增 `0128_restore_builtin_ai_main_url.sql`，只将旧 transit 完整兼容接口替换为主站，兼容首尾空格和大小写，不改第三方及其他路径。
- 系统空默认值补为主站；异常 JSON 结构不强行覆盖，系统其他 JSON 字段及所有原时间字段保持。
- 旧页面再次保存 transit 完整接口时，服务器归一化为当前部署地址；读取旧配置也返回当前地址，数据库批量更新仍由真实迁移完成。
- 测试和私有部署继续使用各自域名，避免跨环境请求。旧 transit 的识别和备用配置防环规则保留兼容，不作为默认请求目标。
- 只修改云端配置处理和前端测试数据，不更改本地程序或重新制作安装包；旧客户端已支持主站接口。

## 验证与发布

真实 PostgreSQL 测试使用临时独立库，检查全部非 URL 字段保持、重复执行、空值、第三方和异常结构。个人配置与充值沿用合成账号及模拟接口的桌面、手机回归，不使用真人配置截图。

本机验收已通过：后端 `internal/httpapi` 和 `cmd/server` 全包、真实 PostgreSQL 新旧地址迁移、配置测试入口路由、12 项页面回归、13 项定向发布脚本测试。发布脚本整套 235 项通过，1 项因未配置该脚本自己的真实 PG 环境跳过；本次 0128 的真实 PG 测试已单独执行。

生产继续通过既有 `auto_deploy.sh` 编排候选构建、隔离数据库演练、新旧完整组合验证和同标签激活。0128 必须绑定固定 SQL 摘要，两张配置表逐行核验，其余旧表和迁移账本继续严格比较，不跳过发布门禁。0127 及历史证据保留原语义。

正式替换数量、公开访问和清理结果以本轮发布证据及激活后的数据库统计为准。任务启动时会获取 AI 配置，已经运行的任务需停止后重新开始以读取新地址。
