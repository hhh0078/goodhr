# 启动前余额检查与充值入口

本文说明岗位和自动回复共用的0.1元启动门槛、充值入口与验证范围。

点击岗位“开始”或自动回复“开始自动回复”时，先读取云端最新钱包余额，不使用顶部胶囊的旧缓存。少于0.1元时不打开招聘平台、不创建任务、不进入招聘账号确认，直接显示“余额不足0.1元，请充值后再试。”。按钮为取消和充值；充值打开现有AI充值弹框，不创建支付订单，不自动继续任务。余额读取失败也不启动，但不会误报余额不足。

用户准备岗位期间余额可能发生变化，真正启动前继续复查。云端岗位启动和自动回复启动均复用同一个最小余额校验，低于1000个最小单位（0.1元）返回AI_BALANCE_INSUFFICIENT，不能绕过前端创建任务。0.1元整允许继续。停止、状态查询和已发生操作的回执不受余额限制。已有消息发送去重和支付确认流程保持原样。

桌面1366px与手机390px测试覆盖：页面原有12元缓存而接口返回0.0522元、取消与打开原充值弹框、0.1元边界允许进入准备、低余额仍可停止自动回复。云端使用隔离PostgreSQL账号和设备认证验证522/999单位不转发执行、1000单位允许、零余额可停止；没有调用真实招聘或支付。

本功能只改云端前后端，不需要重新生成或上传客户端；同轮6.3.4.21本地包继续用于BOSS历史采集修复。Windows与两种Mac架构的客户端不增加系统调用或协议变更。
