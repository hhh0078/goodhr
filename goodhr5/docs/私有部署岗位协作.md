# 私有部署岗位协作

本文说明私有分支 `codex/private-lan-deployment` 的岗位搜索、管理员代改和成员复制功能。

- 在岗位管理顶部输入岗位名称即可模糊搜索，忽略首尾空格和英文字母大小写。搜索与“开启 / 关闭”筛选同时生效，清空搜索可恢复当前状态下的全部团队岗位。
- 团队管理员可点击其他成员岗位上的“编辑团队岗位”图标，复用现有编辑表单。保存后岗位仍归原成员，原统计和历史记录保留。
- 团队成员可点击“复制到我的岗位”图标，打开预填配置的新建表单，调整后保存。岗位名称保留原值，方便与招聘平台的完整岗位名保持一致。
- 副本属于保存人，复制岗位要求、平台和表单支持的筛选配置；默认开启但不会自动运行。运行状态、日志、统计及候选人记录不复制。
- 普通成员只能编辑本人岗位；管理员代改仅限当前团队，不额外获得他人岗位的删除、启动、停止和自动回复权限。成员被移出团队或管理员降级后，后续保存会重新检查权限。
