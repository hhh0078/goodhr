# 累计扫描统计修复开发清单

更新时间：2026-07-23

## 统计口径

- “累计扫描”表示每次岗位运行中从平台读取到的去重候选人数。
- 候选人后续无论打招呼、跳过还是处理失败，都已经发生过扫描，应包含在累计扫描内。
- 同一次岗位运行因滚动重复读取到的候选人不重复累计。
