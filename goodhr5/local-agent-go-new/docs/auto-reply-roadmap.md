# 自动回复迁入 dev

本次以最新主干为基础提炼旧自动回复功能，仅进入 `dev`。`main` 与 `test` 不提前接收自动回复功能。仓库长期保留 `main`、`dev`、`test`，旧功能分支的历史通过仓库外备份恢复。

## 已实现

- 岗位自动回复配置、公司档案和全局启动/停止入口。
- 四个平台的自动回复页面能力、差量消息、候选人身份与岗位核对、发送前后复核。
- 主动打招呼每位候选人前的串行检查点，并保留最新主干筛选记录与异常收尾。
- 本地 AI 工具循环、确认项维护、人工协助通知和运行小窗。
- 本地 SQLite 账号隔离存储，附件私有目录保存，原始聊天和 AI 全文不上传云端。
- 本地文件解析、简历结构化和推荐报告 AI；仅授权后的结构化资料与报告可后台同步云端。
- 本地推荐生成的摘要去重、租约恢复和最多三次尝试；AI 审计最近千条保留。
- 招聘页面零脚本注入，继续使用现有 Camoufox 链路，不带回旧浏览器安装或登录改动。

## 自动验证

本地替身覆盖重启持久化、重复消息去重、不同账号隔离、空字段恢复、存储绑定失败时关闭网络回退、真实 TXT 附件本地提取、AI 动态资料提示词边界和审计引用完整性。最终 Go、Worker、前端构建与跨平台编译结果以本次提交记录为准。

## 待真实账号验证

- 四个平台当前页面的可控新消息发送与候选人收件回读。
- 智联 PDF 新标签保存、关闭及回到原页面的完整过程。
- 猎聘企业端在线简历关闭后的聊天框恢复和附件链路。
- 开启与关闭结构化输出两种情况下的真实账号简历入库、报告和通知。

当前并未把历史招聘平台实测记录冒充本次版本验收，也未发布线上程序或执行生产数据库迁移。
