# 自动回复开发步骤

## 1. 分支规则

- 大分支：`codex/auto-reply`，从最新 `main` 创建。
- 每个阶段建立一个 `codex/auto-reply-*` 小分支。
- 小分支完成后测试、中文提交、推送，再合并回 `codex/auto-reply`。
- 自动回复大分支暂时不合并 `main`。
- 每次合并后更新本文状态、提交号和验证结果。

## 2. 总体验收目标

岗位页可以配置并开启自动回复。猎聘企业端收到候选人新消息后，本地程序可以唯一识别岗位、差量同步聊天、补齐简历、调用支持工具的 AI、维护候选人确认项并安全发送回复；无法处理时只通知 HR，不暂停后续判断。主动打招呼运行时可以在每位候选人前插入最多3个自动回复会话，两个主流程代码保持独立。
