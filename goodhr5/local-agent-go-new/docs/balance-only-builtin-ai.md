## 固定 AI 与接口检查

岗位创建、展示、旧草稿恢复和正常本地快照统一为 `mode_default=ai`。原始存储的 `mode_default=keyword` 或 `detail_mode=ocr` 任一命中时，网页弹框提醒复制名称与要求后删除重建；云端 `/start` 与 `/status` 的 running 路径、本地启动预检均拒绝启动，错误码为 `POSITION_RECREATE_REQUIRED`。云端在模式转换前计算 `requires_recreate`，不自动删除、迁移或改写旧岗位。岗位读取和停止已有任务不受重建检查影响。原筛选模式选择 JSX 注释保留；关键词原文及 `output_structured_resume` 入库选择不删除、不批量修改。详情读取沿用固定平台策略：BOSS 使用 AI，其余平台使用 DOM，不重新引入 OCR。

云端启动岗位前读取该用户的真实 AI 配置，接口必须是 HTTP(S)，真实主机为 `58it.cn` 或其子域名。不接受用户名、路径、查询参数和相似域名伪装；自定义接口返回 `BUILTIN_AI_REQUIRED`，提示前往个人配置查看说明并修改。余额为999单位（0.0999元）不可启动，1000单位（0.1000元）可以启动，拒绝时不得占用运行状态。

个人配置成功读取后才判断接口，读取失败不自动覆盖配置。非内置接口显示说明弹框，只有用户主动点击切换按钮且服务端确认成功才关闭；Esc、遮罩和关闭按钮均不能跳过，失败保留重试。接口地址与 Key 只读，AI 模型使用实际公共配置中的名单与价格，不硬编码 GPT 或其他模型的可用性。

充值弹框与个人配置共用 `BuiltinAIModelSelect`。充值内选好模型即保存，失败保留原选择；自定义接口不得借充值静默切换。切换账号后的旧模型数据和支付确认不得写入新账号。充值活动、实付金额、赠送及退款规则沿用原接口。

- 组件就绪只要求 Node、Camoufox，以及 Windows 必要运行库。即使模拟状态明确 `ocr_installed=false`，也能完成教程；安装请求不携带 OCR。
- 名称填写后直接进入岗位要求，再保存；不显示筛选方式、详情方式和关键词输入步骤。
- 原 `filter-mode`、`detail-mode`、`keywords` 步骤类型保留用于识别旧缓存，恢复时跳到当前真正缺少的字段；返回上一步、重新学习、平台切换和半填草稿同时按固定 AI/DOM 规则处理。
- 去掉活动教程中的“关键词免费、自定义接口、AI需要会员”等旧说明。只有当前岗位的真实终态 **AI** 判断才完成新教程；扫描数和旧关键词终态不算完成。
- 教程联调使用独立内存 Go 后端及协议模拟器，不启动招聘浏览器、不安装真实组件、不调用付费模型。模拟器使用43131/43132隔离端口，阻断真实43129/43130端口；数据库、SMTP均清空连接配置。
