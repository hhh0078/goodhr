# 2026-09-19 详情和关键词回归

## 本轮修复

- OCR / AI 看图不再先要求读取 DOM 正文。Boss 简历使用图片绘制，旧流程会在空 DOM 重试 20 次后退出，尚未执行截图和 OCR。
- Windows OCR 可执行文件查找支持 `.exe` 后缀。
- OCR 各分段分别清理后合并，避免前一段的“牛人分析器”标记截掉后续正文；日志记录分段数量和每段识别字数。
- 设置关键词或排除词时必须读取详情；旧岗位未设置详情模式也不能只匹配列表。关键词判断不再受随机详情打开概率影响。
- 关键词兼容 OCR 断行、空格、零宽字符、全角字符与大小写，保持 AND / OR 和排除词优先规则。
- DOM 模式先滚动加载详情再读取，关键词模式也执行此步骤。
- 所有平台复用的滚轮动作采用变化的距离、分步速度和间隔，仅使用真实鼠标滚轮。截图先确认顶部，相邻段保留至少 35% 重叠，连续两次画面不变才结束。
- 候选人卡片必须完整进入窗口和列表交集后才继续。宽卡片允许缩小横向留白，真正被裁掉的卡片仍不能通过。
- 猎聘企业端关闭入口 AI-Pro 推广遮罩、发送后超级聊聊提示；不点击推广的“免费发起”。同一卡片变成“继续沟通”才确认发送成功，5 秒无法确认则暂停，不盲目重发。推广弹框收尾在成功记账后执行。
