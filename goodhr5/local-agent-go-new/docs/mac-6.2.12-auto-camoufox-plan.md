# Mac 6.2.12.0 自动更新 Camoufox

用户于 2026-10-26 明确选择：自动下载已发布的 Camoufox 修补包，按包 SHA-256 判断，已有旧包也重新下载；不采用仅给旧文件离线补丁的替代方案。

## 实现范围

1. 复用当前 Mac 安装器，发布同时包含 Apple Silicon 与 Intel 主程序的 `6.2.12.0` PKG/ZIP。现有后台按前三段版本变化触发强制更新，只新增 Mac 发布记录，Windows 主程序保留 `6.2.11.3`。
2. Mac 新主程序启动时先关闭浏览器操作入口，首次后台绑定成功后用当次登录凭证请求已有 `/api/runtime/config`。不新增云端接口、不复制组件清单、不保存登录凭证到磁盘。
3. 按本机架构选择资产，Apple 可使用 `mac` 别名，Intel 只能选 `darwin-x64`。比较已安装记录的版本、SHA-256 与实际启动文件；已有旧包或缺失摘要仍需下载，完全相同才跳过。
4. 只复用现有 Camoufox 下载、完整摘要校验、新目录解压、验证及原子登记。保留旧组件与全部 Profile/登录资料；失败不切换到半成品，不继续使用旧浏览器启动任务，允许重试。
5. 已有 Worker 时先确认没有任务，再关闭其浏览器与 Worker。新路径、扩展、原生输入与下载资源准备完成后才放行下一次 Worker 启动，防止进程沿用旧组件路径。
6. 自动检查限定为本次 Mac 主程序启动后的首次绑定阶段，完成后不因重复网页绑定再打断正在使用的浏览器。Windows 的现有流程保持。

## 验收顺序

- 小归档与模拟云端测试：同版本旧 SHA、缺 SHA、全新安装、完全一致不重复下载、不同架构、坏摘要、超时/取消、重复绑定、正在运行任务与失败重试。
- 检查更新期间不能打开浏览器或开始新任务，成功后 Worker 真正使用新目录，原 Profile 和旧组件保留。
- Go 全量测试，Windows amd64、Mac arm64、Mac amd64 编译；Worker 原有检查按实际变化执行。
- 在隔离数据目录和模拟云端运行真实 Mac 主程序，使用已公开校验的 r1 归档及公开网站，验证从旧安装记录自动换包和后续浏览器启动。Apple 原生；Intel 经 Rosetta 的证据单独标记，不冒充 Intel 真机。
- 从干净源码提交构建 universal PKG/ZIP，核对包内容、版本、生产域名、原生依赖与实际运行；不使用真实招聘账号或页面。
- 仅验收通过后经 MCP 上传，比较本机/服务器/完整公网下载 SHA，再备份整行配置并 prepend Mac 独立发布记录。保持 Windows、历史记录顺序、三份 Camoufox r1 与其他配置，保存带并发保护的回退材料。
- 发布前重算空间预算，至少保留 1 GiB，不清理其他任务文件；完成功能提交、推送并合并主分支，再删除本功能分支。

强制更新沿用现有后台不可忽略提示与新任务启动阻断，用户仍需完成 macOS 系统安装。浏览器自动下载发生在新程序连接已登录后台后，不依赖用户再次点击“更新运行组件”。


## 已完成验收

正式包来自干净提交 `3e0efc3108cd8eaa8c13d5f98154c45b053e258d`，使用现有 `scripts/package-release.sh 6.2.12.0 build`。后续 `2d856ae8` 只修正验收脚本的重启复核方式，不改变包内 Go、Worker 或安装器代码。

- Go 全量测试通过：34 个有测试包、8 个无测试包，零失败；Runtime、API、Cloud、Bootstrap 的相关竞态测试通过。配置失败与并发启动的回归测试在旧实现上确实失败，新实现通过。
- Windows amd64、macOS arm64、macOS amd64 编译通过。本次只发布 Mac 主程序；Windows 的启动门闩默认关闭。
- PKG 与 ZIP 内应用的全部文件、符号链接与权限一致。Go 含 arm64/x86_64 两个切片；分别从干净提交按正式参数重编后，SHA 与包内切片逐字节一致。Worker 包含对应两种架构的 impit 原生依赖，版本为 `6.2.12.0`，默认服务地址为正式域名。
- 使用 PKG 解出的真实主程序与 Worker，在两个独立目录预装原始 `152.0.4-beta.30`，再从 oss2 的真实 HTTPS 地址自动下载 r1，完整校验后切换新目录。绑定前与下载中均阻止启动，重复绑定只读取一次清单、下载一次。
- Apple Silicon 原生通过；Intel 使用 Rosetta，Go、Node 与 Camoufox 均为 x64，独立通过。两套正式 Worker 均两次打开公开 `https://example.com/`，登录 Cookie 两次保留；旧启动文件、Profile 标记保留，退出码为 0，无本次浏览器残留。
- 初次只检查 Camoufox，不擅自安装 Node/OCR。全新机器缺 Node 时，失败重试返回明确下一步，避免现有前端空等全部组件；旧 Worker 停止后仍响应则拒绝切换，提示先退出旧程序。
- 现有前端函数和实际弹窗表达式断言通过：旧 Mac `6.2.11.3` 选择 `6.2.12.0` 并强制更新，新版可继续；Windows 仍选 `6.2.11.3`。此项是源码断言，未冒充生产弹窗人工验收。
