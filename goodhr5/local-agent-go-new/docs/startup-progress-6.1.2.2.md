# 6.1.2.2 启动进度

默认交互启动先打开本机进度页面，再检查旧数据、复制和校验。复制、源数据校验、新副本校验与源数据复核分别显示真实已处理字节及当前阶段百分比；扫描目录和收尾阶段显示不定进度。阶段之间百分比重新计数，不代表整体进度倒退。

只有数据准备成功后才创建业务数据库和组件管理器。业务健康接口就绪后，当前标签页进入原控制台，复用已有组件检查、下载、解压提示；组件安装配置和云端服务不变。显式关闭自动打开控制台的后台模式仍不打开页面。

迁移失败时保留原因及关闭按钮，关闭按钮只作用于本次失败的启动实例；正常运行或迁移中不能通过该按钮退出。进度页面只监听回环地址，使用随机访问路径，不输出候选人内容。已有新数据时跳过迁移，不合并或覆盖账号库。

验证使用临时目录中的合成数据，不把用户真实数据搬回 C 盘。Go 测试覆盖逐块进度、迁移完整性、再次启动跳过、失败保留、业务就绪才跳转及跨源关闭拒绝。页面验证覆盖复制进度与失败提示。

本次打包 EXE 的隔离启动尝试被自动审批策略阻止，未绕过；因此不将单元测试和页面预览描述为实际覆盖安装验证。用户机器原有 6.1.2.1 数据保持不动。
