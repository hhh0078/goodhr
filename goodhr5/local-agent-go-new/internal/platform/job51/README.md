# 前程无忧平台适配

本目录由智联平台代码整体复制后逐项修改，平台编号为 `51job`。

- 页面 URL、选择器和行为只在 `config.json`；推荐与搜索两页由本地程序识别并复用已打开的页面。
- `position.go`：按保留括号内容的完整名称匹配，当前岗位相同就保留页面；推荐页使用内联岗位列表，搜索页使用岗位下拉。只有任务明确提供关键词时才提交搜索，不清空其他手动筛选。
- `candidate.go`：继续复用公共候选人读取和真实滚轮。配置只匹配两页当前可见主候选列表，排除SPA隐藏旧页和详情内的相似人选。搜索与切岗只轻量探测加载层、首张卡片和明确空态，完整名单由主流程读取一次。
- `identity.go`：卡片DOM编号末尾包含完整十进制列表序号，不能整体作为人选ID。按实际序号剥除后，仅纯数字简历编号进入 `platform_candidate_id` 和指纹；原编号保存在 `card_dom_id`。每次卡片动作重新解析当前主列表，以最新真实序号定位后核验精确DOM编号；序号、编号不匹配或不唯一就停止。
- `detail.go`：继续复用公共详情能力，正文中出现已加载姓名后才可读取；关闭后确认弹窗消失。
- `greet.go`：只有当前稳定身份的卡片异步变成“继续聊聊”才算成功；不凭 `clicked` 计数。实际按钮需通过真实滚轮进入避开固定页头和底部客服浮层的安全区域，最多三次校正；窗口太矮或积分浮层仍遮挡时立即停止，不刷新岗位或自动重发。
- `followup.go`：从当前唯一卡片重开聊天，电话用礼貌文字索要，绝不点击“获取电话”付费入口；微信走原生确认，附件简历用文字索要。追加消息确认输入框清空；结束时同时关闭聊天和联系人侧栏。
- `reply.go` 保留同源的配置驱动接口，但独立自动回复、附件下载未扩展。`messages_url` 为空，自动回复在启动前明确拒绝。

页面控件命中、输入草稿、展开后取消和实际发送分别验收，不能把单测的模拟发送当作真实发送完成。电话、微信、附件索要及追加消息的实发结果以本次交付验收表为准。

Windows x64、macOS Apple Silicon 和 macOS Intel 共用本目录及原有 Worker，没有系统专属调用、额外依赖或第二条浏览器链路。三种目标的 `job51` 测试程序均已交叉编译通过；这不能替代 Windows/Intel Mac 真机安装与运行检查。

自动回归包含同岗不重选、推荐内联与搜索下拉按名称选岗、名称为空/不存在、保留手动搜索、明确关键词搜索，以及招呼状态确认。真实平台的点击与发送结果应以本次人工可见页面验收记录为准。
