# GoodHR 6.2.4.3 发布验证

- 发布时间：2026-09-30，北京时间；Windows x64。
- 源码提交：`b390cdb0`，修复分支与 `main` 均已推送。

## 修复和测试

- 原因：浏览器窗口仍显示但退到桌面后台时，内容容器未激活，原生鼠标无法可靠工作。直接放行会在鼠标按下阶段卡住。
- 修复：仅在鼠标尚未发出时，按进程祖先定位当前 Worker 启动的 Camoufox 窗口，尝试切到 Windows 前台，核对前台窗口后重新读取目标并重试移动一次。失败时保留详细日志并安全停止，下一次任务重建 Worker。原生输入保护升级到 v10。
- `go test ./...` 通过；Browser Worker `npm test` 156 项通过；前端版本规则 8 项通过。
- 隔离可视浏览器在后台复现故障后，自动切到前台，点击、新标签、输入、滚轮及截图全部通过。真实隔离 v9 浏览器资源升级到 v10 的测试通过。未使用真实 Boss 账号运行岗位。
