## 修复和测试

- 修复 Boss 候选人卡片文字偶尔读取超时或为空时，岗位可能提前停止或漏读候选人的问题。
- 限制同一批次实际并行读取字段的数量；根卡片、姓名和整张卡片文字读取超时后补读。仍读不完整时明确报错并保留诊断信息，不把该卡片悄悄当作已处理。
- `go test ./...` 通过；Browser Worker `npm test` 158 项通过；前端版本规则 8 项通过，`6.2.4.3 → 6.2.5.0` 被判为强制更新。
- 在已登录的真实 Boss 页面刷新后，通过真实鼠标滚轮加载 300 张候选人卡片；以调用参数并发 10 分三批读取，每批 100 张，实际字段读取上限为 4。三批均返回 100 张，姓名和整卡文字无缺失，检测到热搜牛人卡片。测试只读取，未点击或打招呼。
