## 修复内容与验证边界

BOSS 当前详情布局的关闭按钮位于 `iframe[name='recommendFrame']` 内的 `.lib-standard-resume .close-btn`，在 `c-resume` 内层 iframe 外。配置优先查找这一按钮，同时保留旧布局的 `.resume-custom-close`、`.boss-popup__close` 及对应 iframe 路径。

关闭流程先以预期缺失探测判断按钮是否存在；按钮缺失时走既有 Escape 回退，并确认详情弹框已经隐藏。会话失效、取消和其他真实操作错误仍按错误返回，避免把关闭完成后的按钮缺失误报为失败。

旧布局回归使用本机测试页面模拟两个已知布局，通过正式平台配置、Go 关闭流程和真实 Camoufox 执行。它验证了选择器兼容和关闭行为，但并非遍历 BOSS 实际账号的全部 A/B 分组。发布前后真实岗位及遮挡验证都是有限样本，不能承诺未来零错误。
